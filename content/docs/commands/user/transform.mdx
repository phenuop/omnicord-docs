## Overview

Transform into one of your aliens.

Allows you to select and transform into one of your alien companions.

## Usage

```
.transform [alien_id]
```

**Aliases:** `.select`, `.s`, `.tf`

## Features

#### Alien selection

#### Active alien display

#### Battle preparation

#### Quick-switch option

## Examples

```
.transform 5 - Transform into alien ID 5
.transform - View your active alien
```
