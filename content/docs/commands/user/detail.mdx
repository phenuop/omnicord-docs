## Overview

Get detailed information about a specific alien. Shows stats, abilities, and fragment requirements.

Shows comprehensive information about any alien including stats, abilities, evolution paths, and fragment requirements.

## Usage

```
.detail <alien_name>
```

**Aliases:** `.d`

## Information

#### Base stats (Attack, Defense, Speed)

#### Abilities and moves

#### Rarity and evolution stages

#### Fragment requirements for unlocking

#### Battle performance tips

#### Optimal move sets

## Examples

```
.detail heatblast - View Heatblast details
.detail fourarms - View Four Arms details
```
