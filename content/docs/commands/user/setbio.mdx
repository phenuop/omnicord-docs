## Overview

Set or update your profile bio.

Allows you to set or update your profile bio.

## Usage

```
.setbio <text>
```

## Features

#### Text customization

#### Emoji support

#### Character limit: 200

#### Displayed on profile

## Restrictions

#### No harmful or abusive language

#### Default bio is 'I love Omnicord!'

## Examples

```
.setbio I love collecting aliens! - Set your bio
.setbio - Clear your bio
```
