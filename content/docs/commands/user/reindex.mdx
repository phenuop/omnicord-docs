## Overview

Reindex your alien IDs to be sequential.

Reorganizes your alien IDs to be sequential, starting from 1.

## Usage

```
.reindex [confirm]
```

**Aliases:** `.ri`

## Features

#### Preview before confirming

#### One-time operation

#### Cannot be undone

#### Preserves alien data

## Examples

```
.reindex - Preview reindex
.reindex confirm - Confirm reindex
```
