## Overview

Mark or unmark an alien as favorite.

Toggle favorite status for an alien. Favorites are highlighted and appear first in lists.

## Usage

```
.favorite <alien_id>
```

**Aliases:** `.fav`

## Features

#### Quick access to important aliens

#### Visual star indicator

#### Filter by favorites

#### Sort favorites to top

## Examples

```
.favorite 5 - Mark alien ID 5 as favorite
.favorite 5 - Unmark if already favorited
```
