## Overview

Set a nickname for your alien.

Sets a custom nickname for your alien.

## Usage

```
.setnickname <alien_id> <nickname>
```

**Aliases:** `.nick`, `.setnick`, `.nickname`

## Features

#### Custom naming

#### Max 30 characters

#### Remove nickname option

#### Shows in lists

## Examples

```
.setnickname 5 Flare - Name alien ID 5 'Flare'
.setnickname 5 - Remove nickname from alien ID 5
```
