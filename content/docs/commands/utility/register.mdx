## Overview

Register yourself in the Omnicord database to start using commands!

Creates your player profile in the Omnicord database. This is the first step to start your adventure.

## Usage

```
.register
```

**Aliases:** `.reg`, `.signup`, `.join`, `.start`

## Benefits

#### Access to all game features

#### Ability to collect aliens

#### Participate in battles

#### Earn currency and rewards

## Requirements

No special requirements. Just type the command in any channel where the bot can see your message.

## Examples

```
.register - Create your account
```
