## Overview

Convert Tyden to Nullite.

Allows you to convert your Tyden into Nullite currency. Other items can be purchased through the shop command with select menus.

## Usage

```
.buy nullite <amount>
```

## Features

#### Tyden to Nullite conversion

#### Exchange rate display

#### Instant conversion

```
.buy nullite 100 - Convert Tyden to 100 Nullite
```
