## Overview

Buy season backgrounds, battle backgrounds, potions, and passives.

Opens the shop where you can buy and equip season backgrounds, battle backgrounds, potions, and passive abilities using select menus and buttons.

## Usage

```
.shop
```

**Aliases:** `.seasonshop`, `.buyseason`

## Shop Types

### Battle Backgrounds

Cosmetic backgrounds for battles

### Items & Passives

Potions, boost items, and passive abilities

#### Seasonal rotation

#### Select menu interface

#### Button interactions

#### Preview before buying
