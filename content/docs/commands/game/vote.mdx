## Overview

Check voting status and claim rewards for voting for the bot.

Shows your current voting status and allows you to claim rewards for voting. Voting helps the bot get discovered by more users.

## Usage

```
.vote
```

## Features

#### Daily voting reminder

#### Vote streak tracking

#### Bonus rewards for streaks

## Rewards

#### Vote boxes containing anything (Nullite, Tyden, or fragments)

#### Tyden bonuses

#### Special vote-exclusive items

#### Experience boosts

```
.vote - Check vote status
```
