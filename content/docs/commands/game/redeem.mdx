## Overview

Redeem a code to claim rewards.

Allows you to redeem special codes for rewards including aliens, fragments, currency, and items.

## Usage

```
.redeem <code>
```

## Features

#### One-time use codes

#### Time-limited codes

#### Event-specific codes

#### Reward display

## Examples

```
.redeem SUMMER2024 - Redeem a code
.redeem - View available codes
```
