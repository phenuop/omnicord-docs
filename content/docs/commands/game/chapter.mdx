## Overview

Progress through story chapters to earn rewards and unlock new content.

Allows you to progress through the Omnicord story mode. Each chapter offers unique challenges and rewards.

## Usage

```
.chapter [start <id>]
```

## Features

#### Story-driven gameplay

#### Unique challenges per chapter

#### Rewards including aliens, fragments, and currency

#### Chapter-specific achievements

## Examples

```
.chapter - View your current chapter progress
.chapter start 5 - Start chapter 5
```
