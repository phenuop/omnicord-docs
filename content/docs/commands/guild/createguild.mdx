## Overview

Create your own guild.

Creates a new guild with the specified name. Guilds allow players to team up, raid others, and earn exclusive rewards.

## Usage

```
.createguild <guild_name>
```

**Aliases:** `.cguild`, `.guildcreate`

## Features

#### Custom guild name

#### Member management

#### Guild raids

#### Guild shop

#### Leaderboard rankings

## Requirements

Requires 1 guild token. Guild tokens are handled manually by the admin team.

## Examples

```
.createguild OmnicordLegends - Create a guild named OmnicordLegends
.createguild AlienHunters - Create a guild named AlienHunters
```
