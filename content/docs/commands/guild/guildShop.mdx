## Overview

Open the Guild Shop to purchase exclusive guild items.

Opens the guild shop where members can purchase exclusive items using guild currency. All interactions are done via select menus and buttons.

## Usage

```
.guildShop
```

**Aliases:** `.gs`, `.guildbuy`, `.guildshop`

## Features

#### Weekly rotation

#### Exclusive to guild members

#### Better prices than regular shop

#### Will move to web interface for better UI

## Items

#### Guild boosters

#### Exclusive cosmetics

#### Special items

#### Guild perks

## Examples

```
.guildShop - Open the guild shop
```
