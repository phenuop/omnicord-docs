## Overview

Join an existing guild by guild ID.

Allows you to join an existing guild by providing the guild ID.

## Usage

```
.join <guild_id>
```

**Aliases:** `.joinguild`

## Features

#### Auto-join if guild is open

#### Request system for private guilds

#### Guild member limit checking

## Examples

```
.join 12345 - Join guild with ID 12345
.join - View guild join requests
```
