Guild Management Panel to manage your guild settings and members.

A comprehensive management panel for guild leaders to manage their guild using select menus and buttons.

```

```

**Aliases:** `.editguild`, `.guildpanel`

## Features

#### Member management via select menus

#### Role assignment

#### Guild settings

#### Request management

#### Will move to web interface for better UI
