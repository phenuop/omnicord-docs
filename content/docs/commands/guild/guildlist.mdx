## Overview

View the list of available guilds with pagination and detailed info.

Shows a paginated list of all available guilds with their stats.

## Usage

```
.guildlist
```

**Aliases:** `.guilds`, `.listguilds`

## Features

#### Pagination support

#### Guild statistics display

#### Member count

#### Accepting members indicator

#### Ranking information

## Examples

```
.guildlist - View all guilds with pagination
.guildlist 2 - View page 2 of guilds
```
