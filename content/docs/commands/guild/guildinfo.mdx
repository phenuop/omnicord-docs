## Overview

Show all details of a guild by ID with aesthetic UI and member pagination.

Displays detailed information about a guild including members, stats, and rankings.

## Usage

```
.guildinfo <guild_id>
```

**Aliases:** `.ginfo`, `.guilddetails`, `.guild`

## Information

#### Guild name and ID

#### Member count and list (pagination)

#### Guild level

#### Guild currency

#### Current raids

#### Guild shop status

## Examples

```
.guildinfo 12345 - View guild details
.guildinfo - View your current guild details
```
