## Overview

Sends the bot invite link, support server, and website link with an embed, buttons, and select menu.

Provides links to invite the bot to your server, join the support server, and visit the website.

## Usage

```
.invite
```

**Aliases:** `.invitebot`, `.inviteme`

## Features

#### Bot invite link

#### Support server link

#### Website link

#### Interactive buttons

#### Select menu for options

## Examples

```
.invite - Get bot invite links
```
